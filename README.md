Carpeta dedicada a aprender web scraping con scrapy, además de algunos proyectos, de los cuales el más destacado es el que se encuentra en la carpeta "fightmatrix"

# ufc analysis (fightmatrix)
Scrapers para sacar información de matchups y peleadores de próximos eventos y presentarla en un reporte interactivo. Sirve para obtener insights rápidos en un solo lugar, con el fin de priorizar la visualización y análisis de peleas.

Para correrlo ejecutar en la terminal  

uv run python run_pipeline.py "URL de fightmatrix"

Después ir al notebook de Analysis y correr las celdas.
